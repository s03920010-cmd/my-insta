# Instagram Daily Story from Reposts Bot

⚠️ **هشدار مهم**
این اسکریپت از روش غیررسمی (instagrapi) استفاده می‌کند و خلاف قوانین اینستاگرام است.
احتمال محدود شدن یا بن شدن اکانت وجود دارد. با مسئولیت خودت استفاده کن.

## فایل‌ها
- `bot.py` → اسکریپت اصلی
- `videos.txt` → لیست لینک ویدیوهای ریپوست‌شده (هر خط یک لینک)
- `requirements.txt` → وابستگی‌ها
- `session.json` → بعد از اولین لاگین ساخته می‌شود
- `state.json` → پیشرفت (کدام ویدیو را پست کرده)

## نصب
```bash
pip install -r requirements.txt
```

## تنظیمات
1. داخل `bot.py` یوزرنیم و پسورد را وارد کن.
2. لینک‌های واقعی ویدیوهای تب Reposts خودت را داخل `videos.txt` بگذار (لینک‌های مثال را پاک کن).

## اجرا
```bash
python bot.py
```

هر بار فقط **یک** ویدیو را به استوری پست می‌کند و ایندکس را جلو می‌برد.

برای اجرای روزانه از Task Scheduler (ویندوز) یا cron استفاده کن.

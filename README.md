# Instagram Daily Story Bot - نسخه Railway

## هشدار
این بات از روش غیررسمی استفاده می‌کند و احتمال بن شدن اکانت وجود دارد.

## فایل‌ها
- `bot.py` → اسکریپت اصلی (sessionid داخلش گذاشته شده)
- `videos.txt` → لیست لینک‌ها
- `requirements.txt`

## نحوه استفاده در Railway
1. این فولدر را روی Railway دیپلوی کن
2. هر بار که سرویس اجرا شود، فقط **یک** ویدیو را استوری می‌کند
3. برای اجرای روزانه می‌توانی از Cron Job در Railway استفاده کنی

## نکته
اگر sessionid منقضی شد، دوباره از مرورگر sessionid جدید بگیر و داخل bot.py عوض کن.
